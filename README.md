# ركيزة — مؤقت التركيز

مؤقت تركيز بتقنية بومودورو مع قائمة مهام، بالعربي وبالكامل في المتصفح (HTML + CSS + JavaScript بدون أي مكتبات).

## المميزات
- ثلاث أوضاع: تركيز، استراحة قصيرة، استراحة طويلة (كل 4 جلسات)
- حلقة تقدّم متحركة وصوت تنبيه وإشعارات عند انتهاء الوقت
- قائمة مهام وإحصائيات يومية محفوظة في المتصفح
- وضع ليلي، واختصار المسافة للتشغيل والإيقاف
- مدد قابلة للتعديل

الموقع مستضاف على GitHub Pages.
